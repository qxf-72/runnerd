# 任务状态机

## 对外状态

```text
QUEUED
RUNNING
TERMINATING
SUCCEEDED
FAILED
CANCELLED
TIMED_OUT
INTERRUPTED
```

## 合法迁移

```text
QUEUED -> RUNNING
QUEUED -> CANCELLED

RUNNING -> SUCCEEDED
RUNNING -> FAILED
RUNNING -> TERMINATING

TERMINATING -> CANCELLED
TERMINATING -> TIMED_OUT

QUEUED -> INTERRUPTED
RUNNING -> INTERRUPTED
TERMINATING -> INTERRUPTED

```

## 说明

- CANCELLED 表示用户主动取消。
- TIMED_OUT 表示超过执行时间限制。
- INTERRUPTED 表示 runnerd 重启后发现任务之前没有进入终态。
- 超时从任务进入 RUNNING 时开始计算，不包含排队时间。
